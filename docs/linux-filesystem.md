# 📁 Linux Filesystem Structure

## Purpose

Understand the **Linux directory hierarchy** and the role of each directory in system operations.

---

## Root Directory `/`

The top-level directory of the Linux filesystem.

---

## Important Directories

### `/bin`

Essential user commands (ls, cp, mv).

### `/sbin`

System administration binaries (fsck, reboot).

### `/etc`

Configuration files for the system and applications.

### `/var`

Variable data like logs, mail, cache.

### `/home`

User home directories.

### `/usr`

User applications and libraries.

### `/tmp`

Temporary files.

---

## DevOps Use Case

Helps in troubleshooting, log management, and deployments.

---

## Interview Tip

Be ready to explain **/etc, /var, /usr** clearly.
