# 🌐 Networking Commands

## Purpose

Troubleshoot and verify network connectivity in Linux systems.

## Key Commands

* `ip a`, `ip r`
* `ping`
* `ss`, `netstat`
* `curl`, `wget`

## Examples

```bash
ip a
curl http://localhost:8080
```

## DevOps Use Case

Debug application connectivity and port issues.

## Interview Tip

Know difference between `ss` and `netstat`.
