# 🐚 Shell Scripting Basics

## Purpose

Introduce shell scripting fundamentals used to automate Linux tasks.

## Topics Covered

* What is Shell & Bash
* Shebang (`#!/bin/bash`)
* Script execution methods
* Comments

## Example

```bash
#!/bin/bash
# My first script
echo "Hello, DevOps"
```

## DevOps Use Case

Automate simple repetitive commands.
