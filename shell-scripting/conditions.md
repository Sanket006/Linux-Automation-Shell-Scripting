# 🔀 Conditional Statements

## Purpose

Add decision-making logic to scripts.

## Topics Covered

* `if`, `else`, `elif`
* `case` statements
* Exit status codes

## Example

```bash
if [ $1 -gt 80 ]; then
  echo "High usage"
fi
```

## DevOps Use Case

Trigger alerts based on system conditions.

## Interview Tip

Understand test operators.
