# 💽 Disk & Storage Management

## Purpose

Monitor and manage disk usage to prevent outages.

## Key Commands

* `df` – Disk free
* `du` – Disk usage
* `lsblk` – Block devices
* `mount`, `umount`

## Examples

```bash
df -h
du -sh /var/log/*
```

## DevOps Use Case

Prevent disk-full incidents in production.
