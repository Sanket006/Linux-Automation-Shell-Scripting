# 🧠 Linux Internals (DevOps View)

## Purpose

Understand how Linux works internally to improve **troubleshooting and system design**.

---

## Linux Architecture

### Kernel

* Core of the OS
* Manages CPU, memory, devices

### User Space

* Applications and user processes

---

## Boot Process

1. BIOS/UEFI
2. Bootloader (GRUB)
3. Kernel initialization
4. systemd
5. User login

---

## Process Lifecycle

* Creation (`fork`)
* Execution (`exec`)
* Termination

---

## DevOps Use Case

Helps debug boot failures, performance issues, and crashes.

---

Explain **kernel vs user space** clearly.
