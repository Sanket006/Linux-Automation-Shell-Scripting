# ⚙️ Process Management

## Purpose

Monitor and control running processes in Linux systems.

## Key Commands

* `ps` – Process status
* `top` / `htop` – Live monitoring
* `kill` / `pkill` – Terminate processes
* `nice` / `renice` – Priority control

## Examples

```bash
ps aux | grep nginx
kill -9 <pid>
```

## DevOps Use Case

Identify CPU/memory bottlenecks and hung services.

## Interview Tip

Understand process states and signals.
