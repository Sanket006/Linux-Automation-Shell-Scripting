# 👥 User & Group Management

## Purpose

Manage users and groups securely in multi-user Linux environments.

## Key Commands

* `useradd`, `usermod`, `userdel`
* `groupadd`, `groupdel`
* `passwd`

## Important Files

* `/etc/passwd`
* `/etc/shadow`
* `/etc/group`

## Examples

```bash
useradd devops
passwd devops
```

## DevOps Use Case

Access control for servers and CI/CD agents.

## Interview Tip

Know fields inside `/etc/passwd`.
