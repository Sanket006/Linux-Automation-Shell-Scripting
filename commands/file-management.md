# 📁 File Management Commands

## Purpose

Manage files and directories efficiently in Linux systems — a core skill for DevOps and system administration.

## Common Commands

* `ls` – List directory contents
* `cp` – Copy files/directories
* `mv` – Move or rename files
* `rm` – Remove files/directories
* `find` – Search files
* `stat` – File metadata

## DevOps Use Cases

* Log file handling
* Application deployment files
* Backup and cleanup automation

## Examples

```bash
ls -lah
find /var/log -type f -mtime +7
rm -rf old_logs/
```

## Interview Tip

Explain *why* a command is used, not just *what* it does.
