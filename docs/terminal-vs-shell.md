# 💻 Terminal vs Shell

## Purpose

Clarify the difference between a **terminal** and a **shell**, a very common interview topic.

---

## What is a Terminal?

A terminal is an interface that allows users to interact with the shell.

Examples:

* GNOME Terminal
* iTerm
* Windows Terminal

---

## What is a Shell?

A shell is a command-line interpreter that executes commands.

Examples:

* bash
* zsh
* sh

---

## Key Differences

| Terminal     | Shell               |
| ------------ | ------------------- |
| UI interface | Command interpreter |
| Takes input  | Executes commands   |

---

## DevOps Use Case

Understanding shells helps in scripting and automation.

---

## Interview Tip

Say: *Terminal is the window, shell is the engine*.
