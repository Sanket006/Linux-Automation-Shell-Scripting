# 🔁 Loops in Shell Scripting

## Purpose

Repeat tasks efficiently in scripts.

## Topics Covered

* `for` loop
* `while` loop
* `until` loop
* Infinite loops

## Example

```bash
for i in {1..5}; do
  echo $i
done
```

## DevOps Use Case

Iterate over servers, files, or services.

## Interview Tip

Difference between `while` and `until`.
