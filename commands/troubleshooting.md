# 🛠 Linux Troubleshooting

## Purpose

Diagnose and resolve common Linux system issues.

## Focus Areas

* Service failures
* Disk full errors
* Permission issues
* Network connectivity

## Useful Commands

* `journalctl`
* `systemctl status`
* `dmesg`

## DevOps Scenario

Production outage investigation.

## Interview Tip

Always follow a structured troubleshooting approach.
